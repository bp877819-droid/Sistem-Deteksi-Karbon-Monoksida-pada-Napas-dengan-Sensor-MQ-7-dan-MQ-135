# Sistem-Deteksi-Karbon-Monoksida-pada-Napas-dengan-Sensor-MQ-7-dan-MQ-135
Prototipe detektor CO napas portabel. Pengguna menghembuskan napas melalui corong ke ruang sensor. MQ-7 membaca respons terhadap CO, MQ-135 memantau kondisi udara. Arduino Uno mengolah data dan menampilkan nilai serta kategori pada OLED. Ditujukan untuk skrining awal, bukan diagnosis.
